Thanks for downloading my asset pack :)

You should find a PDF called "Setup Guide" in the root folder, which will give you all the guidance you need to get this asset pack working in your project in no time.



The file structure of the project is explained below:

AUDIO FILES
This folder contains raw audio files, including the full music track with intensity variations, as well as individual instrument layers, all as loop-able files.
You won't need to touch this folder if you are using the recommended FMOD implementation as outlined in the Setup Guide.

IMPLEMENTATION
This folder contains the example scene, scripts, prefabs and the FMOD project. The Setup Guide explains in more detail how to use these.
